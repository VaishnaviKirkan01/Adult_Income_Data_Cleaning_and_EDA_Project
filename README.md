# Adult Income Data Cleaning and EDA

A beginner-friendly **Data Science project** where I cleaned and explored the UCI Adult Income dataset using Python.

The main goal was to understand how factors like **education, occupation, age, workclass, gender, working hours, and capital gains/losses** are associated with income above $50K.

### Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

### What I Did

* Cleaned and combined the raw datasets
* Handled missing and inconsistent values
* Checked duplicates and data types
* Created features like `age_group`, `hour_group`, and `net_capital`
* Performed EDA using different charts and statistics
* Analyzed income patterns across different categories

### EDA

I explored:

* Income distribution
* Education vs income
* Occupation vs income
* Age vs income
* Workclass vs income
* Sex vs income
* Working hours vs income
* Capital gain/loss
* Correlations between numerical variables

### Takeaway

This project helped me practice the complete **data cleaning → EDA → visualization → insights** workflow and better understand how to work with a real-world dataset.

> The analysis shows associations in the dataset and does not imply causation.
